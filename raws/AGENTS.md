# Raw Agent 规则

进入本目录前先阅读根目录 `AGENTS.md`、`schema/ownership.md` 和对应的 `schema/sources/` 适配文件。

- 本目录保存来源材料，由同步插件、导入器或经授权的人工/Agent 捕获流程维护；既有 Raw 默认只读。
- 用户明确要求保存特定对话或资料为素材时，可按对应 adapter 新建捕获；创建前检查是否已有同范围材料，不覆盖同名文件。这不授权修改既有 Raw 或插件文件。
- Codex 对话允许摘录、去重、按概念/问答分组及转为表格，前提是忠于声明范围内的来源，保留角色、关键原话和未确认项；详细规则见 `schema/sources/codex.md`。整理得清楚不等于已经编译为 Wiki。
- 不把捕获时新生成的解释、外部补充或 Agent 的学习进度推断冒充原对话；后续持续改写的个人理解留 Workspace，知识综合与质量判断进入 Wiki。
- 捕获后默认冻结；新一轮学习另存新的有界捕获，不覆盖旧理解。明确授权纠正捕获错误时保留原意及更正说明，不借机改写历史。
- 不在既有 Raw 上补写可变分类、状态或跨来源关系，不格式化插件生成正文；来源身份匹配和 Wiki 编译不回写 Raw。
- 调整导入器、同步模板或插件 Raw 是单独配置任务，须明确授权并检查覆盖行为；上述捕获许可不适用于 Douban / WeRead 插件拥有的文件。
- Web / Codex Raw 按捕获年月分片，tags 只保留宽松来源语义；Theme、处理状态和领域判断写入 Workspace 或 Wiki。
- `raws/Douban/_assets/` 是 Douban 插件封面缓存，不作普通附件目录使用。
