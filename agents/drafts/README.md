# Agent 草稿

这里保存 Agent 整理的暂定分析、待审核建议和写作试稿，供后续核实、审阅或继续整理。

- Task 和 Theme 可以链接相关草稿；链接不表示用户已确认其中的判断或设立了新方向。
- 正文使用 `type: draft`，保留已有标题、日期和状态；目录归属不把暂定理解变成个人结论。
- 草稿不自动参与普通 Wiki Query，也不作为 Schema 现行规则。
- 采用后，将需要维护的内容整理到对应 Task、Theme、个人笔记或经 compile 形成的 Wiki 页面；未采用的内容按授权范围保留或归档。
- 不把 Raw 原文复制到这里作为替代来源。
