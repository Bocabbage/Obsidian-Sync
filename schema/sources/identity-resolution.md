# 跨来源身份匹配

跨来源链接由编译来源页承担，不直接在 Douban 与 WeRead Raw 文件之间互相写链接。

## 书籍匹配顺序

1. ISBN 完全一致：可以视为同一版本，但仍检查明显的元数据异常。
2. ISBN 不同、标题与作者一致：标记为相关版本，不自动合并。
3. 没有 ISBN：使用规范化标题、作者、出版社和出版年份生成候选，必须人工或 Agent 复核。
4. 仅标题相似：不得自动合并。

## 作品与版本

- 一个作品可以有多个版本，来源页默认代表可辨识的具体版本。
- 需要跨版本讨论时建立作品实体页，并让各版本来源页链接到该实体。
- `doubanId` 和 `weread bookId` 是平台 ID，不能互相替代。

## 规范化

- 匹配时可以忽略全半角、常见标点、括号中的营销文字和明确的版本装饰词。
- 不在文件系统中批量改名来完成身份匹配；规范化只用于候选比较。
- 合并决定、冲突和人工确认写入来源页正文或迁移记录。

## 编译来源页示例

```yaml
---
type: source
source_type: book
title: Spark快速大数据分析（第2版）
identifiers:
  isbn: "9787115576019"
  douban: "..."
  weread: "41779833"
raw_sources:
  - "[[raws/Douban/book/Spark快速大数据分析（第2版）]]"
  - "[[raws/WeRead/计算机/Spark快速大数据分析（第2版）]]"
---
```
