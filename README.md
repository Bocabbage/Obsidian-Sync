# 我的 Obsidian 知识库

日常做事、学习和整理知识的地方。先把当天要做的事和想到的东西记下来，有了值得持续推进的方向，再逐步连起计划、任务、材料和自己的理解。

第一次回来梳理这套结构，可以从 **[[agents/docs/vault-guide|这个知识库怎么用]]** 开始：目录分工、任务关系和材料流转都有配图，也有学习与旅行两个示例。
