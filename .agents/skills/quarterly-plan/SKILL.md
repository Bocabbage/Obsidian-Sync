# 季度任务管理 (Quarterly Task Manager)

## 子能力

### 2a: 创建季度计划 (Create Quarterly Plan)

**调用方式**：
- `/quarterly-plan create`
- "创建季度计划"、"帮我规划 Q2"、"新建 26Q2"

**交互流程**：
1. 确定季度（Q1-Q4）和年份
2. 选择包含的分类（YEC/SGT/MBE/BBR/SBK，可多选）
3. 从历史季度中提取未完成任务（[>] [\] [ ] 状态）
4. 用户补充/调整每个分类下的任务
5. 生成文件

**文件命名规则**：
- 目录：`workspace/plans/{年份}/quarterly/`
- 格式：`【{年份}】【{分类}】{分类中文名}.md`
- 示例：`【2026】【YEC】开发能力.md`、`【2026】【BBR】语言学习.md`

**模板格式**（以 YEC 为例）：

```markdown
> - [t] **2026-04-01** to **2026-06-30**
```

### 2b: 录入任务进度 (Log Task Progress)

**调用方式**：
- `/quarterly-update`
- "更新任务"、"完成了 YEC-001"、"YEC-003 搞定了"
- "今天的进度：YEC-001→[x], YEC-003→[\]"

**状态映射（表格中使用 Emoji）**：

| 用户说 | Emoji | 含义 |
|--------|-------|------|
| 完成了、搞定了、done | ✅ | 完成 |
| 进行中、还在做、在做 | 🔄 | 进行中 |
| 延期了、改期了 | 🔁 | 重新安排 |
| 暂停了、挂起 | ⏸️ | 暂停 |
| 取消了 | ❌ | 取消/无效 |
| 重要 | ⭐ | 重要标记 |
| 问题 | ❓ | 问题/疑问 |
| 笔记 | 📝 | 笔记 |
| 星标 | 🌟 | 星标 |

**对话流程**：
```
User: 完成了 YEC-001
Assistant:
找到 YEC-001：
  文件：workspace/plans/2026/quarterly/【2026】【YEC】开发能力.md
  当前状态：🔄

更新为 ✅？确认后执行。
  - ✅ 【YEC-001】计算机组成原理 — 阶段一完成
  - 执行记录：| 26-04-03 | YEC-001 | 🔄→✅ | 阶段一完成 |

User: 确认
Assistant: 已更新 YEC-001 状态为 ✅
```

**批量更新**：
```
User: 今天的进度：YEC-001→✅, YEC-003→🔄, SGT-B1→🔁
Assistant: 确认以下更新：
  - YEC-001: 🔄→✅
  - YEC-003: ⬜→🔄
  - SGT-B1: ⬜→🔁
确认？ [Y/n]

User: 确认
Assistant: 已批量更新 3 个任务状态
```

## Task ID 格式

- **Pattern**: `{CATEGORY}-{NUMBER}`
- **Examples**: `YEC-001`, `SGT-B1`, `BBR-002`
- ** NUMBER**: 001-999 数字序号
- ** LETTER**: A-Z 子任务序号
