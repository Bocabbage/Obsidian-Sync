# Wiki Assets

这里保存 Wiki 编译过程中新增、且不由来源插件维护的附件；按领域建立子目录。

- 不复制 `raws/Douban/_assets/` 中已有的来源封面。

- 电影知识附件放在 `wiki/_assets/cinema/`；Douban 海报仍引用 `raws/Douban/_assets/`。
