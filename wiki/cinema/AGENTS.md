# Cinema Agent 规则

进入本目录前先阅读根 `AGENTS.md`、`agents/README.md`、`agents/schema/ownership.md`、`agents/schema/properties.md`、`agents/schema/linking.md` 和 `agents/schema/domains/cinema.md`。

- 本目录保存可复用的电影语言、导演、电影史和作品分析，不保存 Douban 目录副本。
- 个人观感和评分先进入 Workspace Viewing Note；经过 compile 后才成为 Wiki 知识。
- 电影截图、思维导图等领域附件放入 `wiki/_assets/cinema/`，Douban 海报继续引用 `raws/Douban/_assets/`。
