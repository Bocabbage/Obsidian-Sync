# 每日任务 (Daily Task Manager)

## 触发方式

### 晨间（录入任务）
- `/daily`
- "今日计划"、"开始今天"、"今天要做什么"

### 晚间（更新完成）
- `/daily-review`
- "今日总结"、"记录完成"、"今天做了"、"晚上复盘"

## 存储位置

```
workspace/plans/{年}/daily/YYYY-MM/YYYY-MM-DD.daily.md
```

例如：`workspace/plans/2026/daily/2026-04/2026-04-02.daily.md`

## 任务字段

| 字段 | 说明 | 示例 |
|------|------|------|
| `#` | 当日自增序号，从 1 开始 | 1, 2, 3 |
| 任务名 | 本日任务描述 | Java 注解学习 |
| Tag | Quarter Plan 分类前缀 | YEC / SGT / MBE / BBR / SBK |
| 优先级 | 参考 Quarter Plan 体系 | L1 / L2 / L3 / L4 |
| 状态 | 完成情况（见下表） | ✅ / 🔄 / 空 |
| 备注 | 可选 | 提前完成、卡在X处 |

## 状态 Emoji（与 Quarter Plan 一致）

| Emoji | 含义 |
|-------|------|
| （空） | 未开始 |
| 🔄 | 进行中 |
| ✅ | 已完成 |
| 🔁 | 延期/改期 |
| ⏸️ | 暂停 |
| ❌ | 取消 |
| ⭐ | 重要标记 |

## 文件格式

```markdown
> 📅 2026-04-02

## 🌅 今日任务

| # | 任务名 | Tag | 优先级 | 状态 | 备注 |
|---|--------|-----|--------|------|------|
| 1 | Java 注解学习 | YEC | L1 | ✅ | |
| 2 | Spring 配置读取 | YEC | L1 | 🔄 | 事务部分待续 |
| 3 | BI 产品概念梳理 | SGT | L2 | | |

## 🌙 当日总结

> 完成 2/3 | 延期 0 | 取消 0

**备注**：
- 事务传播逻辑复杂，明日继续
```

## 交互流程

### 晨间 `/daily`

```
User: /daily
Assistant: 今天（2026-04-02）要做什么？
  格式：任务名 | Tag | 优先级 | 备注（可选）

User: Java 注解 | YEC | L1
      Spring 配置 | YEC | L1
      BI 概念 | SGT | L2 | 重点看产品文档
Assistant: 已创建今日计划 → workspace/plans/2026/daily/2026-04/2026-04-02.daily.md
```

### 晚间 `/daily-review`

```
User: /daily-review
Assistant: 找到今日计划（2026-04-02），请更新每项状态：
  1. Java 注解学习 → ?
  2. Spring 配置读取 → ?
  3. BI 概念梳理 → ?

User: 1→✅, 2→🔄 事务部分明天继续, 3→❌ 临时取消
Assistant: 已更新，当日总结：完成 1/3 | 进行中 1 | 取消 1
```

## 实现逻辑

1. 判断是晨间（创建）还是晚间（更新）模式
2. 晨间：交互收集任务列表，写入新文件（目录不存在则自动创建）
3. 晚间：读取当日文件，逐条确认状态更新，写入总结行
4. 文件已存在时，晨间模式追加任务而非覆盖
