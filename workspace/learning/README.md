# 学习记录

这里放按 Theme roadmap 组织的个人学习笔记。先确认想学什么、分哪几个阶段，再由 Agent 生成一份主笔记；每个阶段都有“随手记录”和“阶段整理”，从 Theme 的“记录入口”可以直接打开。

听课时先记补充解释、例子、疑问和自己的想法。阶段结束后，再把值得保留的内容整理成更短的说明、对照表、思维导图或作品分析，形式随内容决定。原 PDF 等资料保留在原处，笔记中留下来源链接和定位。

初期每个 Theme 一份主笔记，记录明显增多后再拆页。已有阅读笔记和 `raws/Notes/` 继续在原目录维护。
