# Plans

周、月和季度计划保存在此目录；Daily 已独立到 `workspace/daily/`。

```text
workspace/plans/{年份}/weekly/YYYY-Www.md
workspace/plans/{年份}/monthly/YYYY-MM.md
workspace/plans/{年份}/quarterly/YYYY-Qn.md
```

三种周期统一使用 `period-plan`，同一页面先计划、后复盘；旧计划位于 `archived/`，不自动迁回。
